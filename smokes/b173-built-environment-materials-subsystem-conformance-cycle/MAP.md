# Beta 1.7.3 built-environment materials

This package organizes fourteen construction, navigation, and architectural blocks as one native
material matrix. It closes only their unresolved state, collision, light, tick, and neighbor
dimensions, while retaining each block ID as a first-class Atlas subject and every claim as an
independent knowledge unit.

The state group covers stone, log variants, glass, slab materials, fence, and glowstone. The shape
group distinguishes five full cubes, the two-sixteenths wall ladder, and the two-box cobblestone
stair. The light group records opaque construction materials separately from ladder and fence.
Tick evidence distinguishes the pumpkin family's on-load policy from eleven manual-stable blocks.
Neighbor evidence proves twelve stable materials and a causal ladder support-loss drop.

The profile tag `built-environment` makes this package discoverable without replacing existing
material, direction, luminosity, state, or collision archetypes. Registry, placement, lifecycle,
drops, persistence, rendering, and dimensions already owned by earlier evidence are nonclaims.
