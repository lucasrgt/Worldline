# M30 Remote World Cache

A deterministic adapter fixture feeds native `Packet50PreChunk` fields into
the same cache used by live sessions. It proves two simultaneous decoded chunks,
selective unload eviction, rejection after unload, and the 256-region hard bound.

Two fresh protocol-14 clients then preserve Packet50 lifecycle events while
decoding Packet51 payloads from unmodified official servers. Each exposes at
least one lifecycle-qualified full chunk through an immutable neutral world
view and verifies negative-safe world-to-local block addressing. The exact
spawn chunks and final cache count remain observational.
