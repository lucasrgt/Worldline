# M10 Probe 2 Non-Milestone Decision

Status: accepted

`m10-probe2` is not a Worldline milestone. The historical directory had no
`smoke.properties`, no stable `WorldlineBehavior` identity, no frozen cycle,
and no qualification entry. No tracked directory or Git ref remains in the
current repository.

M10 is represented by the qualified `m10-native-render` boundary. Recreating
`m10-probe2` would require a new behavior identity and a normal milestone
number; the old name may not be used as an implicit or descriptor-free smoke.

This decision intentionally makes no behavioral claim and preserves no runtime
evidence for the abandoned probe.
