# M144 qualification cycle

`StickyPistonPullCycle` builds and extends one sticky fixture, saves it, and
qualifies the extended state through a fresh client before retraction. A third
client proves the pulled state after another save. The complete lifecycle is
repeated in two fresh official server JVMs.
