# M255 qualification cycle

`LavaPlaceCycle` rebuilds the raised stone basin in two fresh official
server JVMs. Each run holds lava bucket `327`, places still lava `11:0`
from the south wall, and reloads the filled cell plus empty bucket
`325:1:0`. One official EOF is retried after a 5 second sleep.

The frozen semantic SHA-256 is
`62a96d88efc9d70f9cef9dc52f4555dbbaf332fb3b578a2c210abfa722ade72d`.
