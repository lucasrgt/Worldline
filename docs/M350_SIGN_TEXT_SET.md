# M350 sign text set

M350 opens the official compound standing-sign plus wall-sign text
boundary. Packet15 of sign item `323` on a raised stone support places
standing sign `63`, then Packet15 against that stone east face places
wall sign `68`. Packet130 writes four lines onto each tile. A fresh
login reads both Packet130 payloads.

The frozen signal includes both block ids `63` and `68` plus the two
tile texts. This compounds M176 standing-sign text and M245 wall-sign
text in one official session. It is not either 1:1 smoke.
