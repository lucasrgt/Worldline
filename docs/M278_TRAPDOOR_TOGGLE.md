# M278 trapdoor toggle

M278 isolates the official wooden-trapdoor open-bit boundary. Item 96 is
placed against a raised stone east face as closed `96:3`, the M163 place
path. Empty-hand Packet15 then toggles open bit `4` so the same cell
becomes `96:7`. The open metadata persists across a clean save plus fresh
login.

Frozen semantic SHA-256:
`a66063d6e5ac041de1eeb23cf5a56d2fe303a9759694e0dd69ce31347ef8442a`.

This milestone does not claim the M163 closed place, a second close
toggle, redstone, waterlogging (absent in this version), or iron trapdoors
(absent in this version).
