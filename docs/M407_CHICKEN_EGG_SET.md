# M407 chicken egg set

M407 opens the official compound chicken identity plus egg `344` boundary.
A default spawner `52` is retargeted from `Pig` to `Chicken`. Packet24 type
`93` must appear in the same session as egg item `344`. Vanilla laying uses
`6000+nextInt(6000)` ticks, so the wait is bounded. When Packet21 `344` is
absent, the actor air-uses family item `344` and Packet23 type `62` freezes
instead. That is distinct from shipping M331 throwables, which have no
chicken.

This milestone does not claim hatch, feather `288`, cooked chicken, XP, or
breeding. Headless `B173WireClient` only. No GUI. No Aero.
