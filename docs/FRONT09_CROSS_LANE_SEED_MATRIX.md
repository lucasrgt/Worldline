# FRONT-09 cross-lane seed matrix

FRONT-09 replaces the original one-point portability sentinel with a permanent
three-seed by four-chunk contract. M114 remains immutable historical evidence;
M634 is the expanded executable sentinel.

The authoritative coordinates live in `smokes/lane-matrix.properties`. The
lane differential accepts only that milestone, validates the Cartesian census,
and records both the portable qualification fingerprint and a digest of the
matrix contract. Windows and Linux records must share the exact clean commit,
tree, contract digest, qualification fingerprint, and semantic digest before a
schema-2 `smokes/lane-portability.lock` can be sealed.

The twelve cases freeze non-air counts and complete solid-occupancy planes.
Mutable surface decoration is an explicit non-claim: the M634 discovery run
showed one surface cell varying between otherwise equal replicas, while every
non-air count and solid-occupancy hash remained stable. The corrected boundary
is recorded as CSM scar `NYA-01M0SYF136ZKGG3DZFA7N91NGX`.

The schema-2 seal continues to authorize portable reuse for the headless
official-server lane only. Client GUI, render, particle, native, Gradle, and
other platform-sensitive lanes remain bound to their own execution identity.
