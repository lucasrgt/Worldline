# M131 qualification cycle

`DualDimensionSessionCycle` first runs a byte-level Packet9/cache fixture, then
repeats simultaneous Overworld and Nether logins in two fresh official worlds.

Both runs must reproduce typed dimensions, player coexistence, sky-light
separation, structural Nether evidence, persisted dimensions, trace and frozen
SHA-256:
`4fbbe9be7e3cd6ab8fbfddd920b11392711702505cfd14044e93128570b457cd`.

Canonical evidence uses two official server JVMs and four client sessions.
