# M298 wood tool crafts

M298 opens the official workbench wooden-tool family craft. Packet15
places table `58`, a second empty-hand Packet15 opens it, Packet100
publishes the 3x3 `Crafting` window, and Packet102/106 assemble oak
planks `5` plus sticks `280` into wooden sword `268`, pickaxe `270`,
axe `271`, shovel `269`, and hoe `290`. The actor takes each result.

Frozen semantic SHA-256:
`2b099c580ef169af939546718df1c4ae560e5f875f92960733fbcc026a3982bf`.

This milestone is distinct from M210 oak-plank placement and from M321's
single wooden-sword craft. It does not claim swinging, durability, tilling,
or combat. Headless `B173WireClient` protocol-14 only. No GUI. No Aero.
