# M247 birch log

M247 opens the official birch-log placement boundary. Packet15 of wood/log
item `17` with damage `2` on a raised stone support places block `17:2`.
That exact upright birch cell remains after a clean save plus fresh login.

This milestone is distinct from M208 oak `17:0` and M246 spruce `17:1`.
Beta 1.7.3 has no log-axis metadata. This path does not claim oak, spruce,
or later axis data values as extra hashed variants.
