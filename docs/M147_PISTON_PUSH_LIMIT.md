# M147 piston push limit

M147 closes both sides of the official Beta 1.7.3 piston capacity boundary. It
adds no API, adapter behavior or local piston evaluator.

Two matched upward-facing normal-piston fixtures use alternating stone `1:0`
and cobblestone `4:0`, making every displacement visible. With twelve payload
blocks, activation extends base `33:1→33:9`, creates head `34:1`, changes all
thirteen chain cells and produces fifteen exact raised-volume changes. With
thirteen payload blocks, the same powered lever leaves the piston and every
chain cell invariant; only the lever changes.

The live incremental cache qualifies the control states. Clean save and fresh
Packet51 snapshots are authoritative for the complete vertical chain, including
the terminal cell. Each side is repeated in a fresh official server pair.

Generated water below the raised support remains outside the causal volume.
This milestone does not claim horizontal or cross-chunk capacity, mixed
immovable chains, sticky retraction, quasi-connectivity, transient block `36`,
collisions, timing, sound or a generic piston implementation.
