# M389 animal drops set

M389 opens the official compound cow and chicken death-drop boundary. Two
default spawners `52` are retargeted from `Pig` to `Cow` and `Chicken`.
Packet24 type `92` dies to Packet7 diamond sword `276` and drops Packet21
leather `334`. Packet24 type `93` dies the same way and drops Packet21
feather `288`. Both drops share one frozen SET.

This is distinct from shipping M149 pig death and M150 pork `319`. It does
not claim cooked meat, XP, milk, eggs, breeding, or hostile loot. Headless
`B173WireClient` only. No GUI. No Aero.
