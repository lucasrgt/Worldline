# M141 qualification cycle

`PigSpawnerCycle` first executes the production Packet24 byte fixture, then
rebuilds the raised default-spawner fixture in two fresh official server JVMs.
Each run correlates one identical pig packet across two clients and enforces
type, identity, metadata and bounded-pose invariants.
