# M150 pig pork drop

M150 completes the official pig lifecycle opened by M141/M148/M149. The session
now owns the last Packet24 identity internally. Callers request observed
movement, Packet7 attack and death without supplying a raw entity id.

After the first nonzero horizontal transition, the actor attacks with a diamond
sword. Both peers decode Packet38 status 3, Packet29 destroy and at least one
Packet21 raw porkchop `319:1:0`. A bounded retry covers vanilla's `nextInt(3)`
zero-drop outcome without freezing drop count or coordinates.

This milestone does not claim generic loot tables, cooked pork, XP, knockback,
hostile AI, saddle state or persistence of the dead mob. The official save after
disconnect only keeps what vanilla already writes.
