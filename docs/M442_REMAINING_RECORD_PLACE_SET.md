# M442 remaining record place set

M442 qualifies the official remaining jukebox place family as one
compound SET. Two jukebox items `84` are placed on a raised stone shelf
as blocks `84:0`. Gold disc `2256` (13) is used on the first cell and
green disc `2257` (cat) on the second. Both cells become `84:1`, both
selected slots empty, and both cells survive a clean save plus fresh
login.

The frozen signal names `place=84x2`, both disc ids, and `eject=none`.
This SET is distinct from M334's play-only Packet61 record SET and does
not claim M398 Packet21 eject or M178's one-cell gold-disc insert.
