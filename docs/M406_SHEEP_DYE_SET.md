# M406 sheep dye set

M406 opens the official compound living-sheep dye boundary. Two default
spawners `52` are retargeted from `Pig` to `Sheep`. Packet7 with rose red
`351:1` and dandelion yellow `351:11` dyes two Packet24 type-`91` sheep.
Packet7 shears item `359` then drops Packet21 wool `35:14` and `35:4`
without Packet38 status 3.

This is distinct from M316 undyed shears-set wool `35` and from wool
crafts M315/M368/M396. It does not claim breeding, wool growth, or
sheep death drops. Headless `B173WireClient` only. No GUI. No Aero.
