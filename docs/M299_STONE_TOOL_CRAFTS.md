# M299 stone tool crafts

M299 opens the official stone-tool workbench family. Packet102 crafts
from cobble `4` and sticks `280` produce stone sword `272`, shovel `273`,
pickaxe `274`, axe `275`, and hoe `291`. Those result IDs remain after a
clean save plus fresh login.

This milestone does not claim wood tools `268`-`271` or `290`, iron or
diamond tools, durability, combat, or generic recipes.
