# M468 tamed wolf assist set

M468 opens the official compound tame-plus-assist boundary. Animals are
enabled so two default spawners `52` can be retargeted from `Pig` to
`Sheep` and `Wolf`. Packet24 type `95` is tamed with bone item `352` via
Packet7 button 0 until Packet38 status `7`. The owner unsits that wolf and
uses one Packet7 button 1 while holding diamond sword `276` against a
fresh Packet24 type `91`. The tamed wolf must continue the fight: Packet38
status `2` on the sheep, then Packet38 status `3` plus Packet29 without a
second player strike.

This is distinct from shipping M420 bone tame plus red-collar dye `351:4`
and from M449 wild pack anger. It does not claim breeding, sitting
persistence, XP, or later wolf armor. Headless `B173WireClient` only. No
GUI. No Aero.
