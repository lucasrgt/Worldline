# M251 qualification cycle

server JVMs. Each run places black wool item `35` (damage `15`) on the
top face, freezes live `35:15`, and reloads that cell after save plus a
fresh login.

`b046e1d6723ba4e19db7d84e49aafbd1dd701fc696e2ce2f6754ad839f4a23be`.
