# M197 qualification cycle

`WoolCycle` rebuilds the raised stone fixture in two fresh official
server JVMs. Each run places white wool item `35` (damage `0`) on the
top face, freezes live `35:0`, and reloads that cell after save plus a
fresh login.

The frozen semantic SHA-256 is
`b6f11e7750a8b8ece43e987d07cc4862caf7e0e44f636b6ffb32f68b0601e8f6`.

Canonical evidence uses two official server JVMs and four client sessions.
