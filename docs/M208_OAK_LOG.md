# M208 oak log

M208 opens the official oak-log placement boundary. Packet15 of wood/log
item `17` with damage `0` on a raised stone support places block `17:0`.
That exact upright oak cell remains after a clean save plus fresh login.

Beta 1.7.3 has no log-axis metadata. This milestone does not claim birch
`17:2`, spruce `17:1`, or later axis data values as extra hashed variants
unless the official server writes them from item `17:0`.
