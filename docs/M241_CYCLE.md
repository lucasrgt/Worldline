# M241 qualification cycle

`IronDoorPlaceCycle` rebuilds the raised stone plus iron-door fixture in two
fresh official server JVMs. Each run places door item 330 and reloads the
placed halves. One typed EOF failure sleeps five seconds and retries that
JVM once.

The frozen semantic SHA-256 is
`a4f2a5f71fe45b70e843d41f32d6a4327eac0d654a488b059ca29eb2a2d261e6`.

Canonical evidence uses two official server JVMs and four client sessions.
