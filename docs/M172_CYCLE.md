# M172 qualification cycle

`WoodenPlateCycle` rebuilds the raised stone wooden-plate fixture in two fresh
official server JVMs. Each run places wooden plate item `72`, powers the cell by
standing on it, depowers by stepping off, and reloads unpowered `72:0`.

The frozen semantic SHA-256 is
`ffcac8ad53202102f7e7ff5179823d53d8ecd116c879faba5a3c1ccf9bcd94c1`.

Canonical evidence uses two official server JVMs and four client sessions.
