# M383 mushroom place set

M383 opens the official compound mushroom-placement set. Packet15 of brown
mushroom item `39` on dirt under a dark stone roof places block `39:0`.
Packet15 of red mushroom item `40` on netherrack under that same roof
places block `40:0`. The frozen signal includes both `39` and `40`. Both
cells remain after a clean save plus fresh login.

This is distinct from shipping M200 (brown mushroom only) and M201 (red
mushroom only). It does not claim huge mushrooms, stew, or daylight
placement. Headless `B173WireClient` only. No GUI. No Aero.
