# M420 wolf tame set

M420 opens the official compound wolf-plus-tame boundary. Animals are
enabled so a default spawner `52` can be retargeted from `Pig` to `Wolf`.
Packet24 type `95` is tamed with bone item `352` via Packet7 button 0 until
Packet38 status `7`. The tamed wolf has the official red collar. Packet7
with dye `351:4` is then used on that living wolf.

This is distinct from shipping M388 skeleton arrows `262` and M406 sheep
dye wool `35:14` / `35:4`. It does not claim XP, breeding, or later wolf
armor. Headless `B173WireClient` only. No GUI. No Aero.
