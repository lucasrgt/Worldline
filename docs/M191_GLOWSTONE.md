# M191 glowstone

glowstone item `89` on a raised stone support places block `89:0`. That
exact cell remains after a clean save plus fresh login.

This is Overworld placement of the Nether light block, not a Nether session.
This milestone does not claim light-plane hashing, silk-touch, or
glowstone-dust drops.
