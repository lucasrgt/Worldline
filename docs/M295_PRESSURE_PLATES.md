# M295 pressure plates

M295 freezes the official wooden-and-stone pressure-plate family together.
Packet15 places wooden plate `72` on the raised stone column and stone plate
`70` on an east pad. Standing on each cell powers it (`72:1`, `70:1`);
stepping off depowers both (`72:0`, `70:0`). A clean save plus fresh login
keeps both unpowered.

This milestone is a set of two plate blocks, not a single-cell map. It does
not claim detector rails, entities other than the actor, or redstone
consumers. Headless `B173WireClient` only. No GUI. No Aero.
