# M247 qualification cycle

`BirchLogCycle` rebuilds the raised stone fixture in two fresh official
server JVMs. Each run places wood/log item `17` (damage `2`) on the top
face, freezes live `17:2`, and reloads that cell after save plus a
fresh login.

The frozen semantic SHA-256 is
`d2edaaf83b9d8b74ec8d46d00e40f224fc12335a5a7e9fd35e7744a490781eb0`.

Canonical evidence uses two official server JVMs and four client sessions.
