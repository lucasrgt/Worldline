# M371 machine-block crafts

M371 opens the official workbench-craft SET for the related machine blocks
TNT `46`, piston `33`, and sticky piston `29` in one isolated compound cycle.

The actor places workbench `58` on the raised-stone fixture, opens that
window, and completes the vanilla recipes: five gunpowder plus four sand to
TNT, three planks plus four cobble plus one iron plus one redstone to piston,
and slime above piston to sticky piston. A second piston is crafted so the
kept piston and the sticky conversion are both present. Packet102 take of
each result slot is accepted only when the official server returns those
exact IDs. The three stacks survive a clean save plus fresh login.

This milestone is distinct from M333 dispenser place/eject and from M294 and
M293 place-only pistons. It does not claim TNT ignition, piston extension,
sticky pull, or dispenser windows.
