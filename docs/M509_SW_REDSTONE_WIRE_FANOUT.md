# M509-SW redstone wire fan-out

M509-SW freezes one bounded T-shaped redstone dust network. The positive phase
powers both branches from one torch-fed source. The negative removes one branch
without depowering the other, and the mutation removes the source so every
remaining dust cell settles to zero.

Two Worldline processes and two official obfuscated-JAR processes must produce
the same exact block IDs and metadata.
