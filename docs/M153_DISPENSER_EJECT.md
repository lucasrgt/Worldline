# M153 dispenser eject

M153 opens the official dispenser-eject boundary. Packet15 places dispenser
`23:4` on a raised stone column. The Trap window (Packet100 type 3, nine
owned slots, 45 combined) accepts one cobblestone `4:0` via Packet102. A
side lever `69:1` attached to the support stone powers to `69:9` and the
dispenser ejects that stack as Packet21. Reopening the Trap window shows
owned slot 0 empty.

This is the Beta 1.7.3 dispenser exception: one random occupied slot is
ejected on a rising redstone edge. The milestone does not claim arrows,
bonemeal, buckets, TNT, fire charges, multi-item RNG, quasi-connectivity,
or hopper insertion.
