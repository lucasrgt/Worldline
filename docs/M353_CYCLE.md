# M353 qualification cycle

`SwordDamageSetCycle` rebuilds the fenced grass platform in two fresh
official server JVMs. Each run Packet7-attacks living pigs with wood
sword `268`, iron sword `267`, and diamond sword `276`, requiring two
non-lethal wood hits then death, and one non-lethal iron and diamond hit
then death. Attacker Packet8 stays `20`. One official EOF is retried
after a 5 second sleep.

Run directly with:

```text
java tools/smoke/SwordDamageSetCycle.java m353-sword-damage-set
```

The frozen semantic SHA-256 is
`cfaf1e0d3a43f1bb3a09cd6dadb2462a7d953de08671761856fc1080249424e4`.

Canonical evidence uses two official server JVMs and two client sessions.
Headless protocol-14 only. No GUI. No Aero.
