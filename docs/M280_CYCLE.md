# M280 qualification cycle

`MagentaWoolCycle` rebuilds the raised stone fixture in two fresh official
server JVMs. Each run places magenta wool item `35` (damage `2`) on the
top face, freezes live `35:2`, and reloads that cell after save plus a
fresh login.

The frozen semantic SHA-256 is
`1c2065b1a6b6a8fdbe04e1a4ed0e9d52b6fa44e7fc16fd931de75c89e017e1fe`.

Canonical evidence uses two official server JVMs and four client sessions.
